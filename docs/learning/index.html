    Beginner vocabulary
    HTTP
    A browser request/response with a method, URL, headers and body.
    TCP socket
    A connection carrying an ordered stream of bytes. Used inside the Java host here.
    Port
    A network endpoint number. API port and file-listener port have different jobs.
    localhost
    The machine executing the code. Here, the server, not the uploader's browser.
    Boundary
    A separator in the multipart upload envelope.
    PIN
    A bearer secret used to find a pending share; not a user login.
    Atomic
    One indivisible state change. Separate safe map operations do not make an entire workflow atomic.
    EOF
    End of stream. It says the stream ended, not that the expected whole file arrived.

    Your two-minute explanation

    Product purpose. Two backends. Upload to server disk. PIN and per-file listener. Download through localhost to HTTP. Successful-path cleanup. One current weakness and a proposed fix. Your actual contribution.

    Say “server-relayed temporary transfer.” Avoid unsupported claims about direct P2P, end-to-end encryption, guaranteed expiry cleanup or exactly-once delivery.
