Start here: classes, objects and the byte path

A class defines a type. new constructs an object of that type. A variable holds a value or an object reference. A method performs an operation when called. A constructor initializes an object. Parameters are call inputs; a return value is an output.

The Java process owns the HTTP API, disk files, maps and TCP listeners. Your browser uploads to this server. The recipient downloads from this server. localhost inside DownloadHandler means this server host.

Browser > UploadHandler > temporary disk + PIN maps > local TCP > DownloadHandler > HTTP > recipient
